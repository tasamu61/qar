# qarシステム
　qarは利用者に質問をなげかけ回答を得、その回答内容によって何らかの提案をすることを目的としたものである。リゾート、旅行に関する質問をなげかけ、利用者の希望に沿った旅行先を提案するものである。  
　これは2002年に作者がフロントがアプレット、バックエンドにPostgreSQLのデータベースをもちいて試行したものである。これは実用には遠かったが、昨今のAI事情により実用化ができるのではないかと考え、フロントはVue.jsを用いて機能拡充をはかったのが現バージョンである。

 　2002年版はアプレットでもあり動作環境もないが、当時の
 [資料](https://tasamu61.github.io/qar/static/doc/2002/inf.html?v1)は残っている。
 <a href="https://qar.tasamu.org">2025年版</a>は利用が可能であり、資料も<a href="static/img/img2025.png">概要</a>、<a href="static/img/sys2025.png">システム内容</a>と簡単なものがある。
 　AIシステムは発展途上にあるというのだろうか、サービス内容の変遷が著しく、APIの仕様、モデルも変わったり、AI独自の微妙な電文解釈、表現が変わることも多く、動作は安定しない。常にAI側の変更をウォッチし、リグレッションテストも毎日流し対応していくといった運用をしないと安定しないのではないかと思う。
 　AIというバックエンドを得て飛躍的な実用性の向上がはかれたが、その仕様変更への対応が困難で実用ベースには届かない状況である。  
 　他にも既存のAIやネット検索と差別化ができていないという課題があり、これらは今後の強化予定である。
